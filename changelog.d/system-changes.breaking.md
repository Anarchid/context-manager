- **Host operators:** take `@animalabs/membrane` 0.7.1 or later in your own range with this release. context-manager now requires `^0.7.1`, where it required `^0.6.1`, since what it stores and compiles is typed with 0.7's `ContentBlock`, which adds `system_change`, and npm installs context-manager's own 0.7 nested beside a host's older membrane without complaint. A host whose own membrane is older doesn't send a stored system change: 0.6's `NativeFormatter` leaves out a block type it doesn't convert. The floor is 0.7.1, not 0.7.0, because 0.7.0 lacks the fix the 0.6.1 floor exists for: a round a provider ends with `stop_reason: end_turn` while holding complete tool calls runs as a `tool_use` round on 0.6.1 and 0.7.1, and ends the turn on 0.7.0.
  - **Migration:** raise the host's own `@animalabs/membrane` range to `^0.7.1`.
  - **Unchanged:** what context-manager stores, and how it calls membrane, for a host that writes no system change.
